# Website Cửa Hàng Văn Phòng Phẩm

Đây là dự án **quản lý cửa hàng văn phòng phẩm**
với mục tiêu *tổ chức dữ liệu và hỗ trợ bán hàng*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| docs | Tài liệu |
| media | Hình ảnh, logo |
| data | Dữ liệu đơn bán |
| logs | File nhật ký hệ thống |
| backup | Bản sao lưu |

## Lệnh sử dụng

Get-ChildItem -Recurse -Force
